# Takbeer Time — v3.3 release notes

## Play Console "What's new" copy

Paste this into Play Console release notes.

```
Takbeer Time 3.3

- New Qaza namaz tracker: record missed Fajr, Dhuhr, Asr, Maghrib, or Isha by date.
- See all unprayed qaza in one drawer and mark each one prayed when complete.
- Qaza reminders now appear in the app when you have pending qaza.
- Updated Android version to 3.3 (124).
```

## Notes

The Qaza tracker is private and stored on this device. It does not submit qaza records to the public masjid timing directory.
